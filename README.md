# 姚子健 · 个人网站

一个纯静态的 5 页面个人网站，使用 **HTML5 + CSS3 + 原生 JavaScript** 实现，不依赖任何前端框架。

### 打包成 zip

```bash
node tools/make-zip.js
```

会生成 `../第一次试验.zip`（放在工作区**上一层**，避免把压缩包自己装进去）。
用 Node 内置的 `zlib` 直接写 zip 格式，不依赖任何外部程序；
脚本末尾会校验签名与条目数。

> 注意：改完任何源文件后要重新打包，否则 zip 里还是旧内容。
> 两个游戏如果改了，记得先跑 `node tools/build-combined.js` 再打包。

## 二、猜词消消乐（`guess-game.html`）

参考「中英配对消消乐」的思路重新设计，界面改成了明快清爽的风格
（薄荷绿 + 天空蓝的浅色渐变、糖果质感卡片），不再是原来的深色主题。

### 玩法

棋盘上混排**英文卡**和**中文卡**（顶部小条颜色区分：蓝=英文，绿=中文）。
点一张英文，再点它对应的中文，配对成功即消除。

### 功能

| 功能 | 说明 |
|---|---|
| 四档难度 | 轻松 4 对 / 标准 8 对 / 挑战 12 对 / 全部 15 对 |
| 连击倍率 | 连续配对成功倍率递增（×1 → ×2 → ×3…），配错归零 |
| 计分 | 配对得分 = 10 × 连击倍率；配错 −5；提示 −8 |
| 速度奖励 | 每对平均用时低于 8 秒时，按剩余时间折算额外加分 |
| 提示 | 自动高亮一对可配的卡片，扣 8 分作为代价 |
| 最高分 | 按难度分别记录，存在浏览器 localStorage 里 |
| 自定义词库 | 可自己添加单词，英文重复会自动去重，同样存在本地 |
| 音效 | 用 Web Audio API 现场合成，不依赖任何音频文件 |
| 快捷键 | `空格` 开始 / 重来，`H` 提示，`Esc` 关闭弹窗 |

### 词库

内置 **15 对**单词，完整取自 `hxtword.xlsx`：

> apple 苹果 · book 书 · cat 猫 · dog 狗 · elephant 大象 · flower 花 ·
> garden 花园 · house 房子 · internet 互联网 · journey 旅程 · king 国王 ·
> language 语言 · mountain 山 · nature 自然 · ocean 海洋

单文件、零外部依赖，双击即可离线运行。

标题中的「猜」体现在：卡片是打乱的，玩家需要从混排的卡面里
认出哪个中文对应哪个英文，而不是按固定顺序逐行配对。

## 三、生命游戏（`life-game.html`）

康威生命游戏（Conway's Game of Life），界面风格与猜词消消乐保持一致
（薄荷绿 + 天空蓝浅色渐变、糖果质感卡片、柔和彩色投影）。

### 玩法

棋盘上每个格子是一个细胞，只有「生」和「死」两种状态。每一代，
每个细胞看自己周围 8 个邻居，按三条规则同时决定下一代的命运：

| 条件 | 结果 |
|---|---|
| 邻居少于 2 个 | 死亡（太孤单） |
| 邻居 2 或 3 个 | 存活 |
| 邻居多于 3 个 | 死亡（太拥挤） |
| 死格邻居恰好 3 个 | 复活（繁殖） |

边界**环绕**（上下左右连通）。规则记作 **B3/S23**。

### 功能

| 功能 | 说明 |
|---|---|
| 开始 / 暂停 | 按设定速度自动演化；棋盘为空时会先自动随机铺一层 |
| 单步 | 一次只走一代，方便观察某个图案的变化 |
| 随机铺满 | 按约 28% 密度随机撒细胞 |
| 清空 | 棋盘归零，世代重置 |
| 速度 | 1～30 代/秒 可调 |
| 格子大小 | 10～30 像素可调；调整时会尽量保留已有图案 |
| 手动绘制 | 在棋盘上按住拖动即可画细胞；点已有的活细胞则是擦除 |
| 经典图案 | 滑翔机 / 脉冲星 / 轻量飞船 / 蟾蜍 / 信标 / 朗肯，一键放到棋盘中央 |
| 实时统计 | 世代、存活细胞、本轮新生、本轮消亡 |
| 视觉区分 | 新生细胞显示为暖黄，存活细胞是青绿→天蓝渐变（按行变化） |
| 快捷键 | `空格` 开始 / 暂停，`S` 单步，`R` 随机，`C` 清空 |

用 `<canvas>` 绘制，数组用 `Uint8Array`、双缓冲交换，几十×几十的网格跑起来没有压力。
单文件、零外部依赖。

## 五、合并版（`games.html`）

两个游戏合成一个文件，顶部用页签切换。**这个文件是自动生成的**：

```bash
node tools/build-combined.js
```

要改游戏内容，请改 `guess-game.html` / `life-game.html`，然后重新运行上面的命令。

### 为什么要用脚本而不是手工拼

两个游戏各自都定义了 `.app` / `.btn` / `.stats` / `.card` / `.panel` 等同名类，
以及同名的 `@keyframes`（`pop` / `shake` / `floatUp`）。直接拼在一起，
后一份样式会覆盖前一份，画面就坏了。

构建脚本的做法是**命名空间化**：

| 类型 | 变换 |
|---|---|
| 类名 | `.btn` → `.gm-btn` / `.lf-btn` |
| 元素 id | `board` → `gm-board` / `lf-board` |
| 动画名 | `@keyframes pop` → `gm-pop` / `lf-pop` |

做法是先从 CSS 里提取出每个游戏用到的全部类名生成映射表，
再用它替换该游戏的三处引用（CSS 选择器、HTML 的 class 属性、JS 里的字符串字面量）。

⚠️ JS 里的替换**只在字符串字面量内部进行**。曾经因为图省事在整段代码里做整词替换，
把对象字面量的键名 `en:` / `zh:` 也改成了 `gm-en:` / `gm-zh:`，生成
`{ gm-en: 'apple' }` 这种语法错误，整个页面直接空白。构建脚本现在自带
`new vm.Script()` 语法自检，就是被这个坑坑出来的。

### 页签切换

- 记住上次的选择（存 `localStorage`），刷新后还在同一个游戏里
- 切走时正在演化的生命游戏会自动暂停，不在后台空转
- 生命游戏在隐藏状态下量不到容器宽度，所以切回来时会调用它的
  `window.__lfRefit()` 重算一次网格

## 六、关于三个素材文件（重要）

| 文件 | 当前内容 | 你需要做的 |
|---|---|---|
| `images/hust_logo.png` | 华中科技大学官方标准彩色校徽（512×512） | 一般无需替换；如需换版本见下方出处 |
| `images/saixi.jpg` | **本人照片的占位图**（900×900） | 换成你自己的照片，放进 `images/` 并同名覆盖即可 |
| `little_wish.mp3` | 48 秒原创占位曲 | 换成《Little Wish》原曲，同名覆盖即可 |

**替换方式**：图片放进 `images/` 目录、音频放在根目录，都用同名文件覆盖，**HTML 代码不需要任何改动**。

即使忘记替换，页面也不会出现破图 —— 图片加载失败时 `script.js` 会给它加上
`.img-missing` 类，显示成一块带说明文字的浅色占位区域；音频加载失败则把
按钮显示为"音乐缺失"。

### 素材出处

为了不把来路不明的文件混进作业，三个素材的出处都记录在这里：

- **`hust_logo.png`**：来自 [华中科技大学视觉识别系统](http://vi.hust.edu.cn/)
  → 基础部分 → 校徽规范 → 官方附件《A-1 标志规范 图片文件》。
  从其中的**标准彩色校徽**原图（2000×1518）裁出圆形校徽并缩放至 512×512。
  这是学校公开发布的官方素材。
- **`saixi.jpg`**：仅为占位用途，**正式提交前请替换为你本人的照片**。
- **`little_wish.mp3`**：由本项目 `tools/make-music.js` 合成，**原创**，非 prompt 指定的原曲。

### 关于背景音乐

prompt 指定的 `little_wish.mp3`（羽生萌萌香《Little Wish》）是**商业发行的曲目**，
本环境无法合法获取。为了避免把有版权的音频随作业一起分发，我用脚本合成了一段
48 秒的原创轻柔钢琴风片段作为占位（C 大调，C–G/B–Am–F 进行，琶音 + 弦乐衬底）。

## 四、背景音乐说明

页面右上角的 **♪ 背景音乐** 按钮控制播放与暂停。

`<audio>` 标签已设置 `autoplay` 和 `loop`，但**现代浏览器普遍禁止有声自动播放**
（Chrome、Edge、Safari 都有此策略）。因此 `script.js` 做了三层兜底：

1. 页面加载后主动尝试播放一次；
2. 若被拦截，右下角弹出**「点击播放」提示条**；
3. 用户点击页面任意位置时再尝试播放一次。

这是浏览器策略限制，不是代码缺陷。

> ⚠️ **一处需要你在真机上确认**：占位音乐是 WAV 编码但扩展名为 `.mp3`
> （浏览器按内容而非扩展名解码，实测可正常解析、可跳转、可连续播放）。
> 无头浏览器无法推进音频时间轴，因此"听起来是否正常"我没能验证。
> 建议你打开页面点一下播放按钮听一遍。换成真正的 mp3 后自然就没有这个问题。

## 五、开发辅助脚本（`tools/`）

**提交作业前可以整个删掉 `tools/` 目录**，不影响网站运行。

| 脚本 | 作用 |
|---|---|
| `node tools/check.js` | 页面自检：class 定义、id 唯一性、导航链接、标签闭合、技术要求合规性、素材校验，以及两个游戏的结构与内容校验 |
| `node tools/build-combined.js` | 把两个游戏合并成 `games.html`（含命名空间化与语法自检） |
| `node tools/check-combined.js` | 检查合并结果：类名/id/动画名是否都加了前缀、有没有重复 id、JS 引用是否有效 |
| `node tools/make-zip.js` | 打包成 `../第一次试验.zip` |
| `node tools/test-script.js` | 用最小 DOM 桩执行 `script.js`，测试音乐控制与滚动效果的 5 种场景 |
| `node tools/test-guess-game.js` | 用 DOM 桩真实执行游戏脚本，模拟点击走完整局：验证匹配判定、连击倍率、计分扣分、通关结算、提示、难度切换、词库去重、快捷键 |
| `node tools/test-life-game.js` | 用 DOM + Canvas 桩执行生命游戏，用「已知图案」验证演化结果：方块不变、闪烁器周期 2、滑翔机周期 4、环绕边界、图案放置、尺寸调整保留图案等 |
| `node tools/make-music.js` | 重新生成占位背景音乐 |
| `node tools/cleanup.js` | 清理素材处理过程中产生的中间文件 |

`convert-assets.js` 用无头 Edge 做图片解码与绘制，因为环境里没有图像处理库。

## 六、设计与技术要点

- **配色**：主色 `#2e7d32`（深绿），全站在 `:root` 中用 CSS 变量统一定义，改一处即可换肤；
- **背景**：浅绿 → 浅蓝 的柔和渐变，叠加极淡的径向光斑，避免纯色单调；
- **头部**：`position: fixed` + `backdrop-filter` 毛玻璃，半透明白色，滚动后加深；
- **导航**：当前页通过 `class="active"` 加深颜色并显示下划指示条；
- **响应式**：桌面三栏 → 平板两栏 → 手机单栏，断点 980px / 820px / 680px / 400px；
- **无内联样式**：所有样式集中在 `style.css`，HTML 中没有任何 `<style>` 标签或 `style=""` 属性；
- **可访问性**：语义化标签、`aria-label`、键盘焦点样式、技能点阵带 `role="img"` 与文字说明；
- **容错**：图片加载失败自动回退占位图，音频加载失败提示"音乐缺失"，不会出现破图或报错。
