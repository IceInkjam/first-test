四年规划

把"想做很多事"拆成四年里每年能完成的具体动作

大一 · FRESHMAN

打牢基础，把工具摸熟

目标：确认自己真的喜欢这个专业，而不是"听起来不错"

  • 学好高等数学、线性代数、工程制图等基础课，绩点保持在专业前 30%
  • 系统练熟 SolidWorks：能独立完成中等复杂度的零件建模与装配
  • 入门 C++，把语法、指针、面向对象的基本概念过一遍，不只是应付考试
  • 用 Arduino 做完至少两个小项目，理解"代码如何控制硬件"
  • 加入一个科技类社团或实验室，先跟着学长学姐做点杂活，感受真实项目的节奏
大二 · SOPHOMORE

补齐短板，进入嵌入式

目标：从"会用工具"过渡到"理解原理"

  • 学习理论力学、材料力学、机械原理，把建模时的直觉换成能算的依据
  • 从 Arduino 转向 STM32：掌握寄存器与 HAL 库、中断、定时器、常用通信接口
  • 对 C++ 进一步深入学习：模板、STL 容器与算法、内存管理、面向对象设计
  • 对 Python 进一步深入学习：面向对象、常用标准库、数据处理与自动化脚本
  • 参加一次校内机械设计或电子设计竞赛，哪怕只是参与其中一部分
  • 通过英语四级，开始能读英文数据手册（datasheet）
大三 · JUNIOR

做出作品，确定方向

目标：手上有一个能拿出去讲、经得起追问的项目

  • 加入实验室参与实际课题，或组队做一个完整的小型机电系统
  • 打通"结构 + 电路 + 程序"：从需求、建模、画板、烧录到联调自己走一遍
  • 对 Java 进一步深入学习：集合框架、多线程、常用工程实践
  • 把三门语言的定位理清楚：C++ 做性能与底层、Python 做算法与工具、Java 做工程与后端
  • 把项目整理成技术文档和演示视频，作为简历和作品集的核心内容
  • 明确毕业去向：保研 / 考研 / 就业，并据此安排这一年剩下的时间
大四 · SENIOR

收口，把路铺到下一站

目标：毕业设计做成一件自己认可的作品，而不是一次应付

  • 认真完成毕业设计，选题尽量与自己感兴趣的方向一致，并做出可演示的实物或系统
  • 补强专业方向课，把四年里零散的知识点串成体系
  • 继续打磨三年前学的那三门语言，把"能用"变成"能独立解决问题"
  • 完成实习或求职准备：简历、项目答辩、技术面试的系统练习
  • 把整个网站更新一遍，让它真实记录这四年的变化
